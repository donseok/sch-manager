# 42병동 간호사 근무표 관리 시스템 - 퀵 매뉴얼

> 대상: 수간호사 / 책임간호사 (근무표 작성 담당자)
> 형식: 2페이지 (PPTX / PDF)

---

## 페이지 1: 시스템 개요 및 근무표 작성/편집

### 1. 시스템 접속 및 메뉴
- 브라우저에서 시스템 URL 접속
- 좌측 사이드바 메뉴: 대시보드 / 근무표 관리 / 간호사 관리

### 2. 근무표 생성 → 편집
- 근무표 관리 → [새 근무표] → 연도/월 선택 후 생성
- 수간호사·책임간호사 자동 배정 (평일=D, 주말=O)
- 셀 클릭하여 근무코드 변경

### 3. 저장 → 확정
- [저장] 클릭 → 변경사항 DB 반영
- 모든 간호사 모든 날짜 입력 완료 후 [확정]
- 월별 1개 근무표만 확정 가능

### 4. 셀 입력 방법
| 방법 | 설명 |
|------|------|
| 클릭 | 셀 클릭 → 팝업에서 근무코드 선택 |
| 드래그 | 마우스 드래그로 여러 셀 범위 선택 |
| Shift+클릭 | 시작 셀 → Shift+끝 셀로 범위 확장 |
| Ctrl+C/V | 선택 영역 복사/붙여넣기 (TSV 지원) |

### 근무코드
| D | E | N | O | X | T | B |
|---|---|---|---|---|---|---|
| 주간 | 저녁 | 야간 | 공휴 | 휴무 | 교육 | 기타 |

---

## 페이지 2: 주요 기능 및 대시보드 활용

### 5. 엑셀 다운로드 / 인쇄
- [엑셀 다운로드] → .xlsx 파일 저장
- [인쇄] → 인쇄 전용 레이아웃 출력

### 6. 이전 월 참조 / 사원 추가
- [이전 월 불러오기] → 전월 확정 데이터 참조
- [사원 추가/제거] → 근무표에 간호사 추가/제외
- [초기화] → 전체 셀 초기화

### 7. 확정 / 확정 취소
- 확정 조건: 저장 완료 + 빈 셀 없음
- 확정 후 편집/저장/초기화 잠김
- [확정 취소] → 다시 수정 가능

### 8. 대시보드 활용 (확정된 근무표 기반)
- 금일 근무현황 — D/E/N/O/X별 간호사 목록
- 주간 미리보기 — 이번 주 근무 배치 파악
- 공정성 지표 — 간호사별 근무 횟수 분포
- 알림 — 연속근무 5일 이상, N→D 연속 배치 경고
- 인력 현황 — 직위별/근무상태별 통계

### 9. 간호사 관리
- 간호사 관리 메뉴에서 등록/수정/삭제
- 필수: 사원번호, 사원명, 직위
- 직위: HN(수간호사), CN(책임간호사), AN(주임간호사), RN(일반간호사)
- 정렬순서로 근무표 표시 순서 결정
